# Swiggy AI Discovery Engine

Analyzing food delivery user friction — why users abandon carts, cancel orders, or switch to competitor platforms.

## Architecture

```
Scrape → Clean → Classify (LLM) → Quantify → Dashboard
```

**Data Sources**: Playstore, Appstore, Reddit, Youtube, Trustpilot, Pissedconsumer

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt
cd dashboard && npm install && cd ..

# 2. Set up environment
cp .env.example .env
# Fill in your API keys

# 3. Run the pipeline
cd pipeline
python run_pipeline.py --mode full --limit 50

# 4. Start the dashboard
cd ../dashboard
npm run dev
```

## Discovery Questions

  1. **Cart Abandonment** — Why do users open the app but abandon their cart before ordering?
  2. **Order Prevention** — What prevents users from completing their food order?
  3. **Restaurant Uncertainty** — What uncertainties remain after selecting a restaurant?
  4. **Order Postponement** — What causes users to postpone placing an order?
  5. **Platform Comparison** — How do users compare food delivery platforms before ordering?
  6. **External Info Seeking** — What information do users seek outside the app before ordering?
  7. **Factor Importance** — What role do price, delivery speed, food quality, hygiene, packaging, and restaurant variety play?
  8. **Intent vs Browsing** — When is the cart genuine order intent vs casual browsing?
  9. **Segment Differences** — How do friction patterns differ across user segments and platforms?
  10. **Unmet Needs** — What unmet needs emerge consistently across user feedback?

## Pipeline Modes

| Mode | Command |
|------|---------|
| Initialize DB | `python run_pipeline.py --mode init-db` |
| Scrape data | `python run_pipeline.py --mode scrape --limit 100` |
| Clean data | `python run_pipeline.py --mode clean` |
| Classify (LLM) | `python run_pipeline.py --mode classify` |
| Export JSON | `python run_pipeline.py --mode export` |
| Full pipeline | `python run_pipeline.py --mode full` |
| RAG server | `python run_pipeline.py --mode rag-server` |
| Stats | `python run_pipeline.py --mode stats` |

## Tech Stack

- **Pipeline**: Python, SQLAlchemy, Pydantic, Gemini/Groq LLMs
- **Dashboard**: Next.js, Recharts, Nivo
- **Database**: SQLite
- **RAG**: FastAPI + scikit-learn vector store
